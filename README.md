# stormcash

First version.

## Workflow

1. Pull the latest `main`, then branch off it with a `feat/` name, e.g. `feat/login-page`.
2. Commit your work on that branch and push it.
3. Open a pull request into `main` and fill out the PR template.
4. Whoever opened the PR merges it once it's ready (**Squash and merge** is the only option, so each PR becomes one commit on `main`).
5. Delete the branch after merging.

`main` is protected: no direct pushes, no force pushes, and no deleting it. Every change goes through a PR.
